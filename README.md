# UnseenAxom

Tap the Assam districts you have visited, add your photo, pick a theme, and download a shareable travel map. Inspired by unseenbangladesh.com's map maker, rebuilt for Assam's 35 districts.

Live: https://sauravhhh.github.io/UnseenAxom/

- Interactive SVG map of all 35 Assam districts (tap to mark visited, search, zoom)
- 4 themes: Gamosa, Brahmaputra, Bihu, Midnight
- Photo + name on the downloaded card
- One-tap PNG download (1080×1350, drawn fully client-side)
- Installable PWA, works offline; selections saved on device

District boundaries: public LGD-derived data (via dhanmoni/tenant-system-prototype), simplified. Names use current official list (35 districts; Karimganj shown as Sribhumi).
